# Asset provenance

- `house-eye.svg`: original vector artwork for this project, by Seigliva and
  contributors, distributed under the repository's MIT license. No Home
  Assistant logo or third-party icon library is used.
- `garage-notification.png`: screenshot supplied by the project owner for publication.
- `camera-preview-blurred.png`: edited from a screenshot supplied by the project
  owner, using the built-in image generation/editing tool. Only the blurred
  derivative is included here, not the original camera screenshot.

- `sign-in.png` and `rule-setup.png`: unmodified screenshots supplied by the
  project owner for publication, showing the compact panel before the tagline
  was restored.

The image-editing prompt was:

> Edit this exact application screenshot for use in its GitHub README. Apply a
> strong privacy Gaussian-style blur ONLY to the camera photograph rectangular
> area in the middle (driveway, house and garden). Make the photograph
> unrecognizable while retaining its broad colors. Preserve the rest of the
> screenshot exactly: all text including G6 Turret Motion, Motion detected, Pin,
> ×, Live · muted, Expand, Open HA; preserve original window outline, dimensions,
> layout, fonts, colors and background wallpaper. Do not redesign the interface.
> Output the complete screenshot with the blurred camera area.

The derivative is illustrative documentation, not a pixel-exact test capture.
